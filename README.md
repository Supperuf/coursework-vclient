# Сетевой клиент vclient

Курсовая работа. Клиентская программа для клиент-серверной системы обработки числовых векторов.

## Требования
- ОС: Linux
- Компилятор с поддержкой C++17
- CMake (3.10+)
- Библиотека OpenSSL (libssl-dev)

## Сборка и запуск
1. `mkdir build && cd build`
2. `cmake .. && make`
3. `./vclient -a 127.0.0.1 -p 33333 -i input.txt -o output.txt`
